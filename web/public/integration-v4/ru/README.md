# Начальный пакет AI Support Widget

Распакуйте ZIP-архив и запустите `node server.mjs`, используя Node.js 22 или более поздней версии. Откройте URL-адрес обратной связи, напечатанный в терминале. Откройте чат поддержки и спросите, почему импорт не удался. В ответе будет указана строка 42 и отображены ссылки на синтетический импорт и ошибки. Сбросьте образец, чтобы начать новый разговор.

`server.mjs` обслуживает образец на вашем компьютере. `starter/sample.js` запускается в браузере и отвечает локальными фикстурами. `widget.v0.3.0.js` — это закрепленная версия виджета. Сравните ее SHA-256 с `widget.manifest.json`.

Загруженный образец открывается на языке этого комплекта. Добавьте `?lang=sr-Latn`, `?lang=sr-Cyrl` или `?lang=ar`, чтобы проверить другую доступную локаль. Передайте выбранную пользователем локаль при монтировании SDK в вашем приложении.

Чтобы интегрировать собственное приложение, удалите скрипт фикстуры и смонтируйте `createBootstrapHandler` из `bootstrap.mjs` на сервере вашего приложения по маршруту, например `/api/support/bootstrap`. Предоставьте `authenticate(request)` из существующего промежуточного ПО сеанса и `collectContext(user, tenantKey, signal)` из вашего уровня данных. Установите частные переменные среды в `backend.env.example`. Инициализируйте виджет с токеном и контекстом, возвращенными этим маршрутом. Установите необязательный `handoffUrl` на вашу страницу поддержки HTTPS. Следуйте [Краткому руководству для разработчиков](https://support-ai.pontes.uk/developers/quick-start?lang=ru) по жизненному циклу сеанса.

Ваш бэкэнд может предоставить `getMcpServers(user, signal)` обработчику начальной загрузки. Верните массив `{id, url, accessToken}` для этого аутентифицированного членства. Создайте кратковременный токен с ограниченной аудиторией для каждого сервера. Опустите обратный вызов для чата только с контекстом. Браузер получает только сеанс виджета и контекст.
