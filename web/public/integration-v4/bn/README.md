# AI Support Widget স্টার্টার

ZIP ফাইলটি এক্সট্র্যাক্ট করুন এবং Node.js 22 বা তার পরের সংস্করণ ব্যবহার করে `node server.mjs` চালান। টার্মিনালে প্রিন্ট করা লুপব্যাক URL খুলুন। সাপোর্ট চ্যাট খুলুন এবং জিজ্ঞাসা করুন কেন ইম্পোর্ট ব্যর্থ হয়েছে। উত্তরে 42 নম্বর সারি চিহ্নিত করা হবে এবং সিন্থেটিক ইম্পোর্ট ও ত্রুটির রেফারেন্সগুলি দেখানো হবে। একটি নতুন কথোপকথন শুরু করতে নমুনাটি রিসেট করুন।

`server.mjs` আপনার কম্পিউটারে নমুনাটি পরিবেশন করে। `starter/sample.js` ব্রাউজারে চলে এবং স্থানীয় ফিক্সচার দিয়ে উত্তর দেয়। `widget.v0.3.0.js` হল পিন করা উইজেট রিলিজ। এর SHA-256 এর সাথে `widget.manifest.json` তুলনা করুন।

ডাউনলোড করা নমুনাটি এই কিটের ভাষায় খোলে। অন্য একটি উপলব্ধ লোকেল পরীক্ষা করতে `?lang=sr-Latn`, `?lang=sr-Cyrl`, অথবা `?lang=ar` যোগ করুন। আপনার অ্যাপ্লিকেশনে SDK মাউন্ট করার সময় ব্যবহারকারীর নির্বাচিত লোকেল পাস করুন।

আপনার নিজস্ব অ্যাপ ইন্টিগ্রেট করতে, ফিক্সচার স্ক্রিপ্টটি সরান এবং আপনার অ্যাপ্লিকেশন সার্ভারে `/api/support/bootstrap` এর মতো একটি রুটে `bootstrap.mjs` থেকে `createBootstrapHandler` মাউন্ট করুন। আপনার বিদ্যমান সেশন মিডলওয়্যার থেকে `authenticate(request)` এবং আপনার ডেটা লেয়ার থেকে `collectContext(user, tenantKey, signal)` সরবরাহ করুন। `backend.env.example` এ ব্যক্তিগত পরিবেশ ভেরিয়েবল সেট করুন। সেই রুট দ্বারা ফেরত আসা টোকেন এবং কনটেক্সট দিয়ে উইজেটটি ইনিশিয়ালাইজ করুন। ঐচ্ছিক `handoffUrl` আপনার HTTPS মানব সমর্থন পৃষ্ঠায় সেট করুন। সেশন লাইফসাইকেলের জন্য [ডেভেলপার সেন্টার কুইক স্টার্ট](https://support-ai.pontes.uk/developers/quick-start?lang=bn) অনুসরণ করুন।

আপনার ব্যাকএন্ড বুটস্ট্র্যাপ হ্যান্ডলারকে `getMcpServers(user, signal)` সরবরাহ করতে পারে। এই প্রমাণীকৃত সদস্যতার জন্য `{id, url, accessToken}` এর একটি অ্যারে ফেরত দিন। প্রতি সার্ভারে একটি স্বল্পস্থায়ী, শ্রোতা-স্কোপড টোকেন তৈরি করুন। শুধুমাত্র কনটেক্সট সহ চ্যাটের জন্য কলব্যাকটি বাদ দিন। ব্রাউজার শুধুমাত্র উইজেট সেশন এবং কনটেক্সট গ্রহণ করে।
