# AI Support Widget سٹارٹر

ZIP کو ایکسٹریکٹ کریں اور `node server.mjs` کو Node.js 22 یا اس کے بعد استعمال کرتے ہوئے چلائیں۔ ٹرمینل میں پرنٹ شدہ لوپ بیک URL کھولیں۔ سپورٹ چیٹ کھولیں اور پوچھیں کہ امپورٹ کیوں ناکام ہوا۔ جواب میں قطار 42 کی نشاندہی کی گئی ہے اور مصنوعی امپورٹ اور غلطی کے حوالہ جات دکھائے گئے ہیں۔ ایک نئی گفتگو شروع کرنے کے لیے نمونے کو ری سیٹ کریں۔

`server.mjs` آپ کے کمپیوٹر پر نمونہ پیش کرتا ہے۔ `starter/sample.js` براؤزر میں چلتا ہے اور مقامی فکسچرز کے ساتھ جواب دیتا ہے۔ `widget.v0.3.0.js` پن کی گئی ویجیٹ ریلیز ہے۔ اس کے SHA-256 کا `widget.manifest.json` سے موازنہ کریں۔

ڈاؤن لوڈ کیا گیا نمونہ اس کٹ کی زبان میں کھلتا ہے۔ کسی اور دستیاب لوکیل کو چیک کرنے کے لیے `?lang=sr-Latn`، `?lang=sr-Cyrl`، یا `?lang=ar` شامل کریں۔ اپنی ایپلیکیشن میں SDK کو ماؤنٹ کرتے وقت صارف کا منتخب کردہ لوکیل پاس کریں۔

اپنی ایپ کو مربوط کرنے کے لیے، فکسچر اسکرپٹ کو ہٹا دیں اور `bootstrap.mjs` سے `createBootstrapHandler` کو اپنے ایپلیکیشن سرور پر `/api/support/bootstrap` جیسے روٹ پر ماؤنٹ کریں۔ اپنی موجودہ سیشن مڈل ویئر سے `authenticate(request)` اور اپنی ڈیٹا لیئر سے `collectContext(user, tenantKey, signal)` فراہم کریں۔ `backend.env.example` میں نجی ماحولیاتی متغیرات سیٹ کریں۔ اس روٹ کے ذریعے واپس کیے گئے ٹوکن اور سیاق و سباق کے ساتھ ویجیٹ کو شروع کریں۔ اختیاری `handoffUrl` کو اپنے HTTPS انسانی سپورٹ صفحہ پر سیٹ کریں۔ سیشن لائف سائیکل کے لیے [ڈویلپر سینٹر کوئیک سٹارٹ](https://support-ai.pontes.uk/developers/quick-start?lang=ur) پر عمل کریں۔

آپ کا بیک اینڈ بوٹ سٹریپ ہینڈلر کو `getMcpServers(user, signal)` فراہم کر سکتا ہے۔ اس تصدیق شدہ رکنیت کے لیے `{id, url, accessToken}` کی ایک صف واپس کریں۔ فی سرور ایک مختصر مدت کا، سامعین کے دائرہ کار والا ٹوکن بنائیں۔ صرف سیاق و سباق کے ساتھ چیٹ کے لیے کال بیک کو چھوڑ دیں۔ براؤزر کو صرف ویجیٹ سیشن اور سیاق و سباق موصول ہوتا ہے۔
