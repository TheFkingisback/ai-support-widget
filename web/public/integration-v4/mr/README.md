# AI Support Widget स्टार्टर

ZIP एक्सट्रॅक्ट करा आणि `node server.mjs` Node.js 22 किंवा नंतर वापरून चालवा. टर्मिनलमध्ये छापलेले लूपबॅक URL उघडा. सपोर्ट चॅट उघडा आणि आयात का अयशस्वी झाली ते विचारा. उत्तर 42 वी ओळ ओळखते आणि सिंथेटिक आयात आणि त्रुटी संदर्भ प्रदर्शित करते. नवीन संभाषण सुरू करण्यासाठी नमुना रीसेट करा.

`server.mjs` तुमच्या संगणकावर नमुना सर्व्ह करते. `starter/sample.js` ब्राउझरमध्ये चालते आणि स्थानिक फिक्स्चरसह उत्तरे देते. `widget.v0.3.0.js` ही पिन केलेली विजेट रिलीज आहे. तिच्या SHA-256 ची `widget.manifest.json` शी तुलना करा.

डाउनलोड केलेला नमुना या किटच्या भाषेत उघडतो. दुसरे उपलब्ध स्थान तपासण्यासाठी `?lang=sr-Latn`, `?lang=sr-Cyrl`, किंवा `?lang=ar` जोडा. तुमच्या ॲप्लिकेशनमध्ये SDK माउंट करताना वापरकर्त्याने निवडलेले स्थान पास करा.

तुमचे स्वतःचे ॲप समाकलित करण्यासाठी, फिक्स्चर स्क्रिप्ट काढून टाका आणि तुमच्या ॲप्लिकेशन सर्व्हरवर `/api/support/bootstrap` सारख्या मार्गावर `bootstrap.mjs` मधून `createBootstrapHandler` माउंट करा. तुमच्या विद्यमान सत्र मिडलवेअरमधून `authenticate(request)` आणि तुमच्या डेटा लेयरमधून `collectContext(user, tenantKey, signal)` पुरवा. `backend.env.example` मध्ये खाजगी पर्यावरण व्हेरिएबल्स सेट करा. त्या मार्गाने परत आलेल्या टोकन आणि संदर्भासह विजेट सुरू करा. पर्यायी `handoffUrl` तुमच्या HTTPS मानवी समर्थन पृष्ठावर सेट करा. सत्र जीवनचक्रासाठी [डेव्हलपर सेंटर क्विक स्टार्ट](https://support-ai.pontes.uk/developers/quick-start?lang=mr) चे अनुसरण करा.

तुमचे बॅकएंड बूटस्ट्रॅप हँडलरला `getMcpServers(user, signal)` पुरवू शकते. या प्रमाणीकृत सदस्यत्वासाठी `{id, url, accessToken}` चा ॲरे परत करा. प्रति सर्व्हर एक अल्प-मुदतीचे, प्रेक्षक-व्याप्तीचे टोकन तयार करा. केवळ संदर्भासह चॅटसाठी कॉलबॅक वगळा. ब्राउझरला केवळ विजेट सत्र आणि संदर्भ प्राप्त होतो.
